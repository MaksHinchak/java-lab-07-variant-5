# Лабораторна робота №7 • Варіант 5

Два потоки, синхронізація та рух машин

Автор: Гінчак Максим Богданович, 241-А.

## Завдання

- 1. Вантажні машини рухаються до випадкової точки верхньої лівої чверті, легкові - нижньої правої. Народжені у цільовій чверті стоять; після прибуття рух припиняється.
- 2. BaseAI як окремий потік над колекцією; TruckAI та CarAI; синхронізація з малюванням, пауза/відновлення через wait/notifyAll та окремі списки пріоритетів.
- Продовження лабораторної 3: Factory і InsuranceCompany збережено як власників автопарків через Vehicle.owner.

## Запуск в IntelliJ IDEA

Відкрийте **саме цю папку Lab07** через File → Open → New Window. Це самостійний проєкт, який не потребує сусідніх лабораторних. Оберіть JDK 17+ у File → Project Structure → Project SDK. На підготовленому Mac вже налаштовано `JBR-25-labs`.

У списку конфігурацій виберіть `Lab07_Main` і натисніть Run. Робоча тека - корінь цього проєкту.

`Lab07_Console` запускає задачу 1 без GUI; `Lab07_Main` запускає графічну задачу 2.

## Запуск у терміналі

```sh
./run.sh
./test.sh
```

Скрипти беруть JDK із JAVA_HOME, установленої IntelliJ або PATH. Для Windows: створіть папку out, виконайте `javac -encoding UTF-8 --release 17 -d out src/*.java`, потім `java -cp out Main` (у PowerShell перелік файлів можна передати через `Get-ChildItem src -Filter *.java`).

## Демонстрація

1. Lab07_Console працює шість секунд, друкує знімки двох потоків і завершується через shutdown/join.
2. У Lab07_Main одразу постав вантажні на паузу: легкові продовжують рух. Віднови перший потік.
3. Зміни пріоритети й поясни, чому швидкість задає V, а не пріоритет.
4. Дочекайся прибуття: координати більше не змінюються. Закрий вікно.

## Уточнення умови

- Початок координат зверху ліворуч; x праворуч, y вниз. Межі цільових чвертей включено.
- --console демонструє задачу 1, звичайний запуск - GUI задачі 2.
- Зерна 51 і 52 дають відтворювані випадкові позиції.
- «Продовжити» не створює новий маршрут після прибуття. Для нового досліду перезапусти програму.
